# Data directory

Everything here is **generated by this repository**. No third-party or real
pharmacy data is used, and nothing here is patient data.

| Path | Contents | Produced by | Committed? |
|---|---|---|---|
| `raw/` | As-generated CSVs: products, sales, inventory, batches | `scripts/generate_data.py` | No (git-ignored) |
| `interim/` | Post-validation, pre-cleaning snapshots and quarantine rejects | validation pipeline | No |
| `processed/` | Cleaned parquet + the leakage-safe modelling dataset | `scripts/build_features.py` | No |
| `medistock.db` | SQLite application database | `scripts/init_db.py` | No |

## Regeneration

```powershell
python -m scripts.generate_data      # deterministic given MEDISTOCK_RANDOM_SEED
python -m scripts.validate_data
```

Generation is seeded (`MEDITSTOCK_RANDOM_SEED`, default `42`) and the seed is
recorded in `manifest.json` and in the dataset documentation. Regenerating with
the same seed and the same generator version must produce byte-identical CSVs;
this is asserted by `tests/regression/test_reproducibility.py`.

## Provenance rules

1. Every artifact manifest records `dataset.version`, `dataset.generator_seed`,
   row counts and the date range.
2. Synthetic origin is disclosed in the API (`DataFreshness.is_synthetic`) and in
   the dashboard footer.
3. No generated file is ever hand-edited. If a transformation matters, it belongs
   in a documented pipeline step.
